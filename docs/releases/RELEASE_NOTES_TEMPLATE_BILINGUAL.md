# LJM Java Manager

## 中文

- 桌面版请选择不带 `nogui` 的 Windows / Linux / macOS 包。
- 无桌面版请选择带 `nogui` 的包。
- 本次更新优化 Java 管理、下载体验和普通用户启动入口。

## English

- Desktop edition: choose the Windows, Linux, or macOS package without `nogui`.
- NoGUI edition: choose the package with `nogui`.
- This update improves Java management, download experience, and regular-user launch entry points.
