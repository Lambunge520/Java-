# LJM Java Manager 2.9.3

## 中文

- 增强 MC 玩家 Java 建议，补充不同发行商的游玩建议和性能差距说明。
- Java 下载界面展示更清晰的 MC 版本、发行商和性能建议。
- 托盘悬浮提示新增工作状态，检查更新、下载、移动、更新/修复、删除/注销时会显示当前状态。
- Release 说明改为中英文双语，并继续保留国内网络下载体验优化。

## English

- Improved Minecraft-focused Java guidance with vendor advice and performance differences.
- Java download view now shows clearer Minecraft version, vendor, and performance guidance.
- Tray hover tooltip now shows work status during update checks, download, move, update/repair, and delete/unregister tasks.
- Release notes are now bilingual, while keeping China network download experience improvements.
