# LJM Java Manager 3.0

## 更新内容

- 新增独立「JVM 参数调整」界面，面向 Minecraft Java 版。
- 可按 PCL、PCL 社区版、HMCL、Java 类型、大版本、MC 版本和电脑配置生成推荐参数。
- PCL 系启动器会拆分头部/尾部参数；HMCL 会提供合并参数。
- 提供稳定、稳定偏性能、最高性能三种方案，并提示可能不稳定的选项。
- Release 资产将附带 Python 源码包，方便用户审查和手动运行。

桌面版请选择不带 `nogui` 的资产；无桌面版请选择带 `nogui` 的资产。

## Update Content

- Added an independent JVM Args page for Minecraft Java Edition.
- Generates presets by PCL, PCL Community, HMCL, Java vendor, Java major, MC version, and PC configuration.
- PCL launchers get split head/tail arguments; HMCL gets combined arguments.
- Includes stability, balanced, and highest-performance profiles with risk notes.
- Release assets will include Python source packages for review and manual runs.

Choose assets without `nogui` for desktop. Choose assets with `nogui` for NoGUI.
