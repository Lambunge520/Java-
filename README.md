# LJM Java 核心环境管家

LJM Java 核心环境管家是一款跨平台 Java 环境管理工具，用于扫描、注册、修复和更新本机 Java 环境，解决 Minecraft、IDE、启动器或其他程序无法识别本机 Java 的问题。

## 主要能力

- 本地 Java 扫描、注册、注销与环境变量设置。
- Java 损坏检测、智能修复与完整修复。
- Java 更新检测、下载、缓存复用、断点续传和 SHA256 校验。
- 多镜像源测速、自动记忆最快源，并优先使用更适合当前网络的源。
- 支持 Eclipse Temurin、IBM Semeru OpenJ9、Azul Zulu、Alibaba Dragonwell、GraalVM、Microsoft Build of OpenJDK、Oracle Java 等多类型 Java。
- 支持 Windows、Linux、macOS，并提供托盘、开机自启、最小化启动和多语言界面。
- 支持 GitHub Release 压缩包热更新，发布 zip、tar.gz、tgz 包也可以被工具自动识别并替换。
